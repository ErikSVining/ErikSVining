## Projects: Current Works in Progress

### Quadcopter Drone with RaspberryPi Controller

This is a basic hobby FPV (First Person View) quadcopter drone that I am building and designing with a 
RaspberryPi Zero W logic board that will handle the majority of the computational work. Specifically, it
will be handling the camera input and use image recognition to steer and guide the drone around obstacles
and to follow targets. It is coded in Python right now, but as the scope widens, new languages may be needed.

Links to this project's repository will be added as the project progresses.

### Rocket Self Contained Guidance System

This is still very much a work in progress, but the design concept is based around a Level 1 High Power Rocketry Certification flight
through the National Association of Rocketry. The rocket will be designed around a H size motor and will feature radio communications as well
as GPS for recovery. Also, it will feature onboard stabilization and guidance using servo-motor controlled fins.

This project is still very much in the planning and design phase, so more details about system architecture and design will be added as
it is decided.

Links to this project's repository will be added as the project progresses.
